Support the plugins

All plugins are and will remain free and open source for everyone. Donations are voluntary gifts: no rewards, no priority support, no exclusive content, no early access.

If you find them useful and want to chip in, you can do it here:

GitHub Sponsors

Monthly or one-time. Requires a GitHub account.

Ko-fi

One-time tips via PayPal or card. No account needed.

Donations help cover the Apple Developer Program fee (so macOS builds ship signed and notarized), the sognevo.com domain and infrastructure, and test hardware. If you'd rather not donate, reporting bugs, sharing presets or telling a friend helps just as much.
