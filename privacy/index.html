Privacy

No cookies, no accounts, no ads, no forms, no telemetry in the plugins. This page lists the little that is left, in plain words.

Analytics

This site counts page views with GoatCounter. It sets no cookies and builds no visitor profiles: it briefly looks at your IP address and browser signature to tell people from bots and to avoid counting the same visit twice, then keeps only aggregate numbers. Nothing identifiable is stored, and nothing follows you to other sites. Details are in the GoatCounter privacy policy.

Third parties

When you load a page here, your browser also talks to a few external services. Each of them sees your IP address, as any web server does:

GitHub. The site is hosted on GitHub Pages, the plugin pages ask the GitHub API for the latest release so the download buttons stay current, and the downloads themselves come from GitHub releases. See the GitHub privacy statement.

Google Fonts. The two typefaces on this site are served by Google's font servers. See the Google privacy policy.

Donations. If you donate, that happens entirely on GitHub Sponsors or Ko-fi, under their own privacy policies. This site never sees your payment details.

Email

If you write to andrea@sognevo.com, your address and message are used only to reply to you. They are not shared with anyone and you will not end up on a mailing list, because there isn't one.

Your rights

Sognevo is run by one person, not a company. Under the GDPR you can ask what data exists about you and have it corrected or deleted; given the above, the honest answer will usually be "none". For any request or question, write to andrea@sognevo.com.
